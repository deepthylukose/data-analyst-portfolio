# TaskFlow SaaS Usage & Retention Analysis

## Project Overview
This project analyzes user activity and subscription patterns
for a simulated SaaS application.

## Tools Used
- SQL
- Google BigQuery
- Tableau

## Business Questions
- How many monthly active users are there?
- Which subscription plan has higher user engagement?
- What are the most frequently used application features?
- How active are users across different subscription plans?

## Key Findings
- Total users: 500
- Active users: 499
- Average recorded events per user: 20.04
- Paid users: 183
- Free users: 317
